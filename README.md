# E-tutor

E-tutor is a responsive e-learning website built using React.js, Tailwind CSS and Framer Motion. It has a clean, modern UI with smooth animations and works well on mobile, tablet and desktop screens.

## Technologies Used

- React.js
- Tailwind CSS
- Framer Motion
- Vite
- JavaScript (ES6+)

## Features

- Responsive Navbar
- Hero section
- Banner section
- Subject cards
- Animated number counter
- Why Choose Us section
- Testimonials section
- Footer
- Smooth animations using Framer Motion
- Fully responsive design

## How to Run

1. Clone the repository

```bash
git clone https://github.com/VaruRoshani/E-tutor.git
```

2. Go to the project folder

```bash
cd E-tutor/my-project
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

5. Open the link shown in the terminal (usually http://localhost:5173/)
